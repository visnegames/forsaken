🌙 About The Game
Forsaken is a dark pixel indie adventure set in a forgotten kingdom swallowed by darkness.
Explore abandoned castles, uncover lost relics, follow ancient quests and discover the secrets hidden beneath the moonlit ruins.
---
🎮 Features
Dark fantasy pixel world
Combat-focused exploration
Atmospheric environments
Legendary items and quests
Forgotten castles and dungeons
Dark ambient soundtrack
